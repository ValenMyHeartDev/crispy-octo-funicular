# Bloon Lyrics

Un mod para **Minecraft 1.21.11** (Fabric) que detecta y muestra letras de canciones en tiempo real sincronizadas desde Spotify y YouTube en el HUD del juego.

## Características
- Sincronización de letras vía LRCLIB API.
- Renderizado elegante en tiempo real en la pantalla (HUD).
- Estructura limpia para Fabric 1.21.11 (Java 21).
